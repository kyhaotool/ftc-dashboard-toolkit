Chương 01 / Cấu trúc của một trangTrang 02 — HTML
Markup · Structure · Meaning

MỌI THỨ
BẮT ĐẦU TỪ HTML.

Nếu website là một ngôi nhà, HTML chính là khung nhà, cửa sổ và những căn phòng.

HTML viết tắt của HyperText Markup Language. Nó dùng các thẻ để mô tả nội dung và cấu trúc trang. Trình duyệt đọc những thẻ đó rồi hiển thị kết quả.

Thẻ thường có cặp mở và đóng. Ví dụ, <p> bắt đầu đoạn văn, còn </p> kết thúc đoạn đó. Một số thẻ như <img> không cần thẻ đóng kiểu này.

01 / hello-world.html
<h1>Xin chào, Internet!</h1>
<p>Đây là website đầu tiên.</p>
<a href="https://example.com">Nhấn vào đây</a>
  1. 01.

    Thẻ tiêu đề

    <h1> là tiêu đề chính; từ h1 đến h6, cấp độ giảm dần.

  2. 02.

    Đoạn văn

    Dùng <p> để nhóm nội dung thành một đoạn dễ đọc.

  3. 03.

    Liên kết

    Thuộc tính href cho biết liên kết sẽ mở tới đâu.

Thử thách: đổi tiêu đề.

Sang Phòng lab, sửa chữ trong thẻ <h1>, nhấn “Chạy thử” và quan sát kết quả.

Chương 02 / Nghệ thuật trình bàyTrang 03 — CSS
Style · Layout · Rhythm

CẤU TRÚC CÓ RỒI.
GIỜ HÃY CHO NÓ CHẤT.

CSS biến cấu trúc đơn giản thành một trải nghiệm có cá tính.

CSS là Cascading Style Sheets. Bạn dùng nó để điều khiển màu, phông chữ, khoảng cách, đường viền và cách các phần tử sắp xếp. Một quy tắc có bộ chọn, thuộc tính và giá trị.

Hãy giữ nội dung và trình bày tách biệt để giao diện nhất quán hơn. Khi biết Grid, Flexbox và media query, bạn đã có bộ công cụ mạnh để thiết kế trang responsive.

02 / style.css
body {
  font-family: sans-serif;
  background: #f3ead7;
  color: #202820;
}
.headline {
  font-size: clamp(2rem, 6vw, 5rem);
  line-height: .95;
}

Chương 03 / Trang web biết phản hồiTrang 04 — JavaScript

ĐỪNG ĐỂ TRANG WEB
CHỈ ĐỨNG YÊN.

JavaScript thêm hành vi: bấm nút, cập nhật nội dung và kiểm tra câu trả lời.

HTML mô tả nội dung, CSS định hình diện mạo, JavaScript giúp trang phản ứng. Biến giữ giá trị, hàm gom những bước thực hiện, còn sự kiện báo rằng người dùng vừa làm điều gì đó.

03 / interaction.js
// Lắng nghe lần nhấn nút
const button = document.querySelector("button");
button.addEventListener("click", () => {
  alert("Bạn vừa chạy JavaScript!");
});

THE END IS
JUST THE START.

Mọi người đều từng là người mới bắt đầu. Dòng code tiếp theo là của bạn.

CODE/PAPER là bản mẫu tạp chí học lập trình mang cảm hứng xuất bản công nghệ thập niên 1990. Thiết kế kết hợp giấy ngả màu, đường kẻ biên tập, kiểu chữ tương phản và tương tác trình duyệt hiện đại.

Nội dung giới thiệu HTML để cấu trúc, CSS để trình bày, JavaScript để thêm hành vi. Phòng lab thử HTML trong iframe được cô lập; bài trắc nghiệm chạy hoàn toàn trong trình duyệt.
