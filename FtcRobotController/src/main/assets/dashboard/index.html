PID FORMULAS
ZIEGLER-NICHOLS
Kp = 0.6 * Ku
Ki = 2 * Kp / Tu
Kd = Kp * Tu / 8
PID OUTPUT
Output = Kp*error + Ki*integral + Kd*derivative + Kf*feedforward
ERROR
error = target - current_position
INTEGRAL
integral += error * dt
DERIVATIVE
derivative = (error - last_error) / dt
TUNING GUIDE
START
Set Ki=0, Kd=0. Increase Kp until robot oscillates.
STEP 2
Set Kp = 0.5 * oscillation_value. Increase Ki slowly.
STEP 3
Add Kd to reduce overshoot. Fine-tune all values.
