## Season: All game (2026-20XX)

## Getting Started

### Requirements
- Android Studio Ladybug (2024.2) or later
- FTC SDK Version 11.1.0

### Setup
1. Open Android Studio
2. File → Open → Select this project folder
3. Wait for Gradle sync to complete
4. Connect your Control Hub via USB
5. Click Run to upload

## Hardware Config Names (create on Robot Controller)
- `frontLeft` - Front Left Motor
- `frontRight` - Front Right Motor
- `backLeft` - Back Left Motor
- `backRight` - Back Right Motor
- `imu` - BNO055 IMU
